# Список покупок

Одноекранний Android-застосунок для лабораторної роботи 2 з програмування Android-застосунків. Варіант 1.

## Функції

- введення назви товару та додавання кнопкою «Додати»;
- неактивна кнопка для порожнього поля;
- список товарів у `LazyColumn` з унікальним UUID для кожного елемента;
- перемикання стану «куплено / не куплено» натисканням на картку або прапорець;
- перекреслення назви купленого товару;
- реактивний лічильник «Залишилось купити: N».

## Архітектура

Стан зберігається у `ShoppingViewModel`:

- `_items: MutableStateFlow<List<ShoppingItem>>` — перелік товарів;
- `_newItemName: MutableStateFlow<String>` — текст поля введення;
- `remainingCount` — похідний `StateFlow`, створений через `items.map { ... }`.

`MainActivity` отримує значення потоків за допомогою `collectAsStateWithLifecycle()`. Composable-функції не зберігають стан самостійно: вони тільки відображають дані та передають події до `ViewModel`.

## Запуск

1. Відкрити папку проєкту в Android Studio.
2. Дочекатися завершення Gradle Sync.
3. Запустити модуль `app` на емуляторі або пристрої з Android 10 (API 29) чи новішим.
